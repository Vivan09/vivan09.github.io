Privacy Policy

VoMu Trend Hunter · Effective November 4, 2026

VoMu Games home

This policy covers VoMu Trend Hunter, the internal keyword research tool of VoMu Games. Each of our mobile games has its own privacy policy, linked from its Google Play listing.

Who uses the tool

The tool is used only by the owner of VoMu Games. It is not offered to the public, and no one else signs in to it.

Google user data the tool accesses

The tool asks for one Google permission: access to the Google Ads API (scope https://www.googleapis.com/auth/adwords) for the studio's own Google Ads account. With it, the tool reads:

  • keyword ideas and search-volume estimates from Keyword Planner for keywords the owner chooses;
  • the customer ID of the studio's Google Ads account, which is needed to make those requests.

The tool does not request access to Gmail, Google Drive, contacts or any other Google service. It does not create or change campaigns, ads, budgets or billing.

How the data is used

Search-volume estimates are used only to judge how many people search for a game name or trend, so the studio can decide which games to make. The data is not used for advertising, is not sold, and is not used to build profiles of people. It is not used to develop, improve or train generalized artificial intelligence or machine learning models.

How the data is stored

  • The OAuth refresh token is kept as an encrypted secret in the settings of the studio's private GitHub repository and in a local file on the owner's own computer.
  • Search-volume estimates are stored as aggregate numbers next to trend keywords in the same private repository. These numbers describe search activity in general and contain no information about any individual.

Sharing

Google user data is not shared with, transferred to or sold to anyone. Aggregate search-volume numbers may appear in the studio's own private dashboards.

Retention and deletion

Aggregate numbers are kept while they are useful for research. Access can be revoked at any time at myaccount.google.com/permissions. After access is revoked, the stored token is deleted and no new data is read.

Google API Services User Data Policy

VoMu Trend Hunter's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
